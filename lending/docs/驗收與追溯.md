## 四、規格未定義而停止的地方（不自行發明）

以下情形系統會丟出 `E_PENDING_DECISION`，停止該功能並要求人工決策：

1. 計息方法與利率單位的組合未在規格「庚」列出（例如「按日365 ＋ 固定金額」）。
2. 到期日模式不是 `ADD_DAYS` 或 `INCLUSIVE_DISBURSE_DAY`。
3. 沖帳覆寫或付款人指定含未知分量代碼。
4. 契約載有遲延利息規則但非結構化格式：標 `PENDING`，不計入應收，不填 0。

## 五、必須法律審查、程式不得當判決（二）

`slos/compliance.py::LEGAL_REVIEW_TOPICS` 逐條列出並在旗標中回傳：

1. 日息／期息如何折成年利率以適用民法第 205 條
2. 某筆費用是否構成民法第 206 條巧取利益
3. 某經營型態是否需特許
4. 是否構成刑法第 344 條重利（需處境要件，不能只看利率）
5. 民法第 323 條「費用」是否包含契約違約金

系統不得自動宣告整筆借貸無效，不得自動入罪。
