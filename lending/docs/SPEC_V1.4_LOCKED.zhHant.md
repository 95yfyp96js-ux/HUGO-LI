# 〇、施工代理硬性規則（不得違反）

1. 不得自行改業務規則、會計規則、計息、沖帳規則。
2. 不得新增本規格未列為「必須」的 V1 功能。
3. 不得刪除稽核軌跡。
4. 已入帳交易不得 UPDATE、不得 DELETE。只能沖正＋更正。
5. 規格自相矛盾時必須停止，標記「待決策／規格衝突」，不准猜。
6. 未知資料只能存：MISSING（缺）、UNKNOWN（有但尚未辨識）、N/A（不適用）、PENDING（流程未完）、NOT_VERIFIED（未核驗）。禁止用 0 或空白代替未知。
7. 金額一律 Decimal。幣別 TWD。入帳小數 2 位。利息中間值 8 位。入帳時四捨五入到 2 位。
8. 下一階段開始前，本階段 P0 自動化測試必須全過。
9. 禁止實作：投資人、資金池、群眾募資、分潤、AI 徵信、串聯徵、鑑價、法律意見引擎。
10. 建立案件 ≠ 核准貸款。本系統永不核貸。

# 一、紅隊結論（已接受）

V1.3 不得施工。

致命問題：
- 做成銀行 12 期月繳年金，實際是 7／10／15／30 天到期結清。
- 利率只存年利率一個欄位。
- 用期金表驅動應收。
- 出現「已核准／待撥款」等銀行授信狀態。
- 把 Excel 當作業系統與帳本。
- 把銀行消金違約金公式當民間預設。
- 每日應收快照、PAR30 當核心畫面。
- 展期可能把利息滾入本金。

保留：
- 契約 → 應收 → 實收 → 沖帳 → 分戶帳
- 實收 ≠ 沖帳
- 已入帳不可改
- 銀行只是外部資金證據
- 資金來源僅出借人自有資金
- 不做授信

# 二、法規釘選（官方，全國法規資料庫）

確定事實：
- 民法第 203 條：應付利息而未約定利率、亦無法律可據者，週年百分之五。
- 民法第 204 條：約定利率逾週年百分之十二者，經一年後，債務人得隨時清償原本，但須一個月前預告；此權利不得以契約除去。
- 民法第 205 條：約定利率超過週年百分之十六者，超過部分之約定無效。
- 民法第 206 條：不得以折扣或其他方法巧取利益。
- 民法第 207 條：利息不得滾入原本再生利息。例外極窄（書面、遲付逾一年、催告等）。
- 民法第 233 條：金錢債遲延得請求遲延利息；對利息無須支付遲延利息。
- 民法第 250–252 條：得約定違約金；過高法院得酌減。
- 民法第 321–323 條：清償人得指定抵充；未指定則依法定順序；提出之給付應先抵充費用，次充利息，次充原本。
- 民法第 474、478 條：消費借貸因交付而成立；應於約定期限內返還。
- 民法債編施行法第 10-1 條：修正後第 205 條，於修正施行後發生之利息債務亦適用。
- 銀行法第 29、29-1 條：非銀行不得收受存款；向多數人或非特定人吸收資金並給付顯不相當報酬，以收受存款論。
- 個人資料保護法第 2、19、20 條：姓名、身分證字號、聯絡方式、財務情況屬個人資料；非公務機關蒐集處理須有特定目的與法定事由（含契約關係）並採安全措施；利用應於目的內。

必須法律審查、程式不得當判決：
- 日息／期息如何折成年利率以適用第 205 條
- 某筆費用是否構成巧取利益
- 某經營型態是否需特許
- 是否構成刑法第 344 條重利（需處境要件，不能只看利率）
- 第 323 條「費用」是否包含契約違約金

推論（系統預設，不是法律判決）：同一案件內，無指定時依「契約費用 → 利息 → 本金 → 暫收」沖帳。沒有契約就不得自動評估違約金。

# 丙、業務規則（已鎖）

BR-001 建立案件不是核貸。沒有核准狀態欄。  
BR-002 同一客戶可有多案，已結清與進行中可並存。  
BR-003 一案多個契約版本，僅一筆「目前版本」。  
BR-004 改利率、天數、計息、違約金、沖帳覆寫＝新版本。舊列不得改那些欄。  
BR-005 帳上本金以實撥為準。契約面額與實撥分開存。  
BR-006 到期日依 D01 由當時契約版本計算；展期後用新版本到期日。  
BR-007 到期應收＝未償本金＋未收利息＋契約費用＋契約違約金。不得自創費用。  
BR-008 基準日晚於到期日且應收大於 0.005：狀態＝逾期。  
BR-009 到期後遲延利息僅在契約有規則時才算。推定年利率逾 16% 只打旗標。  
BR-010 禁止對利息再計息。  
BR-011 禁止自動複利。利息轉本金必須調整指令＋法律審查標記；預設拒絕。  
BR-012 預設沖帳 ALC-V1。付款人指定優先。  
BR-013 溢繳進暫收。不是收入。不是負本金。  
BR-014 沒有案件編號的匯入進暫收「無法認列」。禁止只靠金額自動猜案件。  
BR-015 同一帳本＋同一冪等鍵不得重複入帳。  
BR-016 已入帳列不可變。  
BR-017 月份已關帳，作業員不得入帳。管理員重開必須寫原因。  
BR-018 缺銀行流水 ≠ 事件不存在。  
BR-019 利率用類型欄位保存。系統核心不得寫死任何利率數字。  
BR-020 年利率估超過 16%：打旗標，超額不認列為可執行利息收入。若該利率單位無法折年：打「上限無法換算」＋法律審查，仍保存契約原額，不准默默砍。  
BR-021 畫面預設 7／10／15／30；自訂 1–365；>90 旗標；>365 拒絕。  
BR-022 展期＝新契約版本＋新到期日＋同一案件編號＋保留歷史。  
BR-023 先結清再開新案＝新案件，不是展期。  
BR-024 核銷不刪案件。之後收款＝收回。  
BR-025 V1 入帳幣別僅 TWD。  
BR-026 時區台北。日期用日曆日。時間戳記含時區。  
BR-027 證據編號不得空字串，必須是哨兵詞或真實編號。  
BR-028 結清試算 ≠ 已結清。  
BR-029 核銷、重開帳期、利息轉本金、超過單筆調整上限：要管理員。單人模式寫警告。  
BR-030 預設匯出為遮蔽版。

# 己、狀態機

案件：草稿 → 已撥款 → 進行中 → 部分已還／逾期／已展期／已結清／已核銷  
草稿可取消。已結清不得同時進行中。已撥款必須有已入帳撥款。

撥款／收款：草稿 → 已入帳 → 已沖正。已入帳不能直接取消。

結清：試算中 → 過期或已入帳。案件要等入帳後尾差小於 0.005 才變已結清。

對帳：待對／已配／部分配／未配／重複／例外／缺證據。

# 庚、計息引擎

輸入：本金、利率值、利率單位、計息方法、日曆、期間定額、起日、迄日、進位、契約版本。

- 期間定額＋固定金額：滿期收該金額；部分還且非 sticky 則依剩餘天數／原天數比例再四捨五入。
- ACT/365＋年利率：本金 × 年利率 × 天數 ÷ 365
- ACT/365＋日利率：本金 × 日利率 × 天數
- ACT/360：分母 360
- 滿期且起日＝撥款日、迄日＝到期日：天數用借款天數，避免閏年差一天
- 自訂公式 V1 拒絕
- 利息不得為負

畫面與測試名稱用繁中：「期間定額」「按日 365」。

---

# 辛、應收引擎

只在事件落地快照：撥款、部分還、到期、展期、結清試算、（選擇性）日結。  
不做每天排程產 30 張快照。  
必須能重算核對上一張快照。

---

# 壬、收款引擎

先建實收，再預覽沖帳，確認後才入帳。  
無案件編號 → 暫收「無法認列」＋現金增加＋貸暫收。  
禁止只靠金額自動配案。

---

# 癸、沖帳引擎

順序：契約覆寫或預設「費用→利息→違約金→本金」，剩餘暫收。  
無違約金規則則跳過違約金。  
本金不得沖成負數。  
每一筆沖帳列必須記下當時規則編號。

---

# 子、分戶／現金／總帳

分戶分量：本金、利息、費用、違約金、暫收貸方。  
現金：收入／支出／轉帳。轉帳淨額為零，不是收入。  
科目：1000 現金、1010 銀行、1100 應收本金、1110 應收利息、1130 應收費用、1120 應收違約金、2100 暫收、4100 利息收入、4110 費用收入、4120 違約金收入、9990 調整。  
V1 利息收入預設「收到才認列」。應收引擎仍追「該收多少」。  
分錄不平衡不得入帳。

---

# 丑、對帳／結清／展期／帳齡／暫收

對帳比對順序：流水＋金額＋方向＋日期正負兩天。禁止只靠金額自動標「已配」。  
結清試算與結清入帳分開。  
展期 7／10／15／30 或 1–365 自訂。不覆蓋舊契約。  
續借＝先結清再開新案號。  
帳齡：未逾期、1–7、8–15、16–30、31–60、61 以上。分量分開列。  
PAR30＝逾期天數 ≥30 的未償本金。不得另定義。  
暫收原因：溢繳、無法認列、方式不明、契約缺口。超過 3 日在儀表板標高。

---

# 寅、調整、沖正、核銷、稽核、權限、個資

沖正產生反向分錄，原列標已沖正。  
調整永遠新增。利息轉本金預設拒絕。  
核銷不刪案。之後收款走收回。  
稽核必記：建立、入帳、沖正、調整、展期、結清試算、結清入帳、核銷、收回、看完整個資、匯出、關帳、重開、改設定。稽核表禁止改、禁止刪。

個資畫面預設：
- 身分證：A123****89 這種格式
- 電話：09**-***678
- 帳號：********1234
- 地址：只留區級，路名遮蔽  
禁止在資料模型收病歷、犯罪前科等個資法第 6 條特種資料。
