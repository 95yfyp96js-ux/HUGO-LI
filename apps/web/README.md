# 網頁版第 1 版：一個網址，員工登帳、老闆收盤

電腦與 iPhone Safari 同一套。規格見
[`docs/BOSS-SPEC.md`](../../docs/BOSS-SPEC.md)。

## 有什麼

| 誰 | 看得到／做得到 |
|---|---|
| **員工** | 8 個按鈕（新增客戶、新增借款、確認撥付、收票、收款並核銷、票兌現、票退票、看今日流水）＋自己今天的流水。**看不到活盤五格、看不到日結。** |
| **老闆** | 員工能做的全部 ＋ 活盤五格（含格 2 拆「未到期／已到期未處理」）＋今日未核銷紅字 ＋ 日結一張表與四關（核定／確認／認證）。**四關只有老闆能按。** |

認證後那一天（含之前）**鎖帳**：收款、收票、兌現、退票、補登撥付一律被後端擋掉，
不是把按鈕藏起來。要更正只能開更正單（本版尚未提供）。

## 跑起來

```bash
cd apps/web
dart pub get
dart run bin/seed.dart          # 假資料（可略）
dart run bin/server.dart        # http://localhost:8080
```

第一次啟動會建兩個帳號並把密碼印在主控台（只印一次）。要自己指定就先設環境變數：

```bash
BOSS_PASSWORD=... STAFF_PASSWORD=... dart run bin/server.dart
```

其他環境變數：`PORT`（預設 8080）、`DB_PATH`（預設 `ledger.db`）。

```bash
dart analyze   # 預期 No issues found!
dart test      # 預期 76 支全過
```

## 幾條寫死的規矩

- **金額權威在伺服器。** 分配（罰息→費用→利息→本金）、罰息計提、五格、盤不平、
  日結，全部在 Dart 後端算，攤還公式直接呼叫 `packages/lending_engine`
  （沒有重寫、沒有編成 JS）。頁面**沒有任何 `<script>`**，有測試盯著。
- **`op_id` 在 GET 組表單時就發**，`operations` 表 `UNIQUE(op_id)`；狀態變更一律
  條件更新（`WHERE status='held'`、期別 compare-and-set）。雙擊、重送、Safari
  上一頁再送，都只成立一次。
- **停用帳號即時生效。** 每次請求重查帳號狀態，不是只看 cookie。
- **權限在後端判。** 老闆專屬的路由前端不畫按鈕，後端再檢查一次角色（403）。
- **計畫表結構重算。** `schedule_items` 只存「已繳了多少」，每期本金／利息／到期日
  由引擎依貸款條件重算。有人手改資料庫金額而沒留分錄，重放就對不上，
  右邊打「盤不平」、日結不准認證。
